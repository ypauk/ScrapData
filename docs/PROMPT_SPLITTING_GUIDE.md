# Как отправлять большие промпты в бесплатный ИИ

## Проблема

Твои промпты на этапах scraper/parser = 500-5000 строк (15-30k токенов).
Бесплатные ИИ:
- ChatGPT free: режет длинный ввод или теряет начало
- Gemini free: принимает большой ввод, но хуже следует инструкциям в начале
- DeepSeek: принимает, но качество падает на длинных промптах

## Решение: prompt_splitter.py

Скрипт разбивает промпт на части и даёт их тебе по очереди для копирования в чат.

---

## Быстрый старт

```bash
# Разбить последний сгенерированный промпт:
python prompt_splitter.py

# Разбить конкретный файл:
python prompt_splitter.py projects/amazon/AI_OUTPUT/03_scraper_prompt.md

# Свой лимит строк (по умолчанию 200):
python prompt_splitter.py --max-lines 150

# Сохранить в файлы (если clipboard не работает):
python prompt_splitter.py --save
```

---

## Как это работает

### Было (1 промпт, 800 строк):

```
[РОЛЬ + ПРАВИЛА + АНАЛИЗ + ПЛАН + AI_INPUT + ЯДРО ПРОЕКТА + ШАБЛОН + ЗАДАЧА]
→ Всё в одном сообщении → ИИ теряет инструкции → плохой код
```

### Стало (4 части по 200 строк):

```
Сообщение 1: "Запомни контекст. Часть 1/4. [РОЛЬ + ПРАВИЛА + АНАЛИЗ]"
ИИ: "Часть 1 принята. Жду следующую."

Сообщение 2: "Часть 2/4. [ПЛАН + AI_INPUT]"
ИИ: "Часть 2 принята. Жду следующую."

Сообщение 3: "Часть 3/4. [ЯДРО ПРОЕКТА]"
ИИ: "Часть 3 принята. Жду следующую."

Сообщение 4: "Последняя часть 4/4. Весь контекст получен. ТЕПЕРЬ выполни задачу. [ШАБЛОН + ЗАДАЧА]"
ИИ: → Генерирует код с учётом ВСЕГО контекста
```

## Что происходит в чате ИИ

### Часть 1 (ты вставляешь):
```
ВАЖНО: Я буду отправлять тебе контекст проекта по частям.
Это часть 1 из 4.
Запомни всю информацию ниже. НЕ отвечай и НЕ генерируй код пока не получишь последнюю часть с задачей.
Ответь ТОЛЬКО: "Часть 1 принята. Жду следующую."

---

# РОЛЬ
Ты — Senior Python Web Scraping Engineer...

# ПРАВИЛА
1. Не менять структуру каталогов...

# АНАЛИЗ
Задача: собрать товары с amazon.com...
```

### ИИ отвечает:
```
Часть 1 принята. Жду следующую.
```

### Часть 2 (ты вставляешь):
```
Это часть 2 из 4. Продолжение контекста.
Запомни. НЕ отвечай и НЕ генерируй код.
Ответь ТОЛЬКО: "Часть 2 принята. Жду следующую."

---

# ПЛАН ПРОЕКТА
scraper.py: функция fetch_page_data()...

# ДАННЫЕ КЛИЕНТА
URL: https://amazon.com/s?k=laptop...
```

### ... и так далее до последней:

### Последняя часть (ты вставляешь):
```
Это последняя часть (4 из 4).
Весь контекст получен. ТЕПЕРЬ выполни задачу.

---

# ЗАДАЧА
Сгенерируй полный рабочий код для app/scraper.py...
```

### ИИ отвечает:
```python
# Полный рабочий код scraper.py
import requests
from typing import List
...
```

## Рекомендуемые лимиты по ИИ

| ИИ | max-lines | Почему |
|----|-----------|--------|
| ChatGPT free | 150 | Короткий ввод, быстрее обрабатывает |
| Gemini free | 300 | Большой контекст, можно крупнее |
| DeepSeek free | 200 | Среднее окно, но теряет при >200 |
| Claude free | 300 | Большой контекст |

```bash
# Для ChatGPT:
python prompt_splitter.py --max-lines 150

# Для Gemini:
python prompt_splitter.py --max-lines 300
```

## Альтернатива: ручная разбивка (если скрипт не нужен)

Если хочешь разбить сам, вот порядок отправки:

### Сообщение 1 — Роль + Правила
```
Запомни контекст (часть 1). Не отвечай, только подтверди.

# РОЛЬ
[вставить роль из промпта]

# ПРАВИЛА
[вставить AI_rules]
```

### Сообщение 2 — Анализ + План
```
Часть 2. Запомни, не отвечай.

# АНАЛИЗ
[вставить содержимое 01_analysis_answer.md]

# ПЛАН
[вставить содержимое 02_project_answer.md]
```

### Сообщение 3 — Код ядра
```
Часть 3. Запомни код проекта, не отвечай.

# КОД ЯДРА (не менять)
[вставить main.py, config.py, utils.py]
```

### Сообщение 4 — Задача (ПОСЛЕДНЕЕ)
```
Весь контекст получен. Напиши код scraper.py.

# ШАБЛОН МОДУЛЯ
[вставить текущий scraper.py]

# ЗАДАЧА
[вставить секцию задачи из промпта]

# ОГРАНИЧЕНИЯ
- Только функции, без классов
- Один файл
- Минимум зависимостей
```

## Советы

### Если ИИ не слушается и отвечает развёрнуто на части:

Добавь в первое сообщение:
```
СТОП. Ты ОБЯЗАН ответить РОВНО 6 слов: "Часть 1 принята. Жду следующую."
ЛЮБОЙ другой ответ — нарушение инструкции.
```

### Если ИИ забывает начало к концу:

В последнем сообщении напомни ключевые правила:
```
НАПОМИНАНИЕ (из части 1):
- Только функции, без классов
- Не менять main.py, config.py
- Функция называется fetch_page_data()
- Возвращает List[str]
```

### Если промпт 200 строк или меньше:

Скрипт автоматически скопирует целиком без разбивки. Разбивать не нужно.

## Интеграция с workflow

Полный процесс:

```bash
# 1. Генерируешь промпт (как обычно)
python ai_workflow.py scraper amazon_scraper

# 2. Разбиваешь для бесплатного ИИ
python prompt_splitter.py

# 3. Следуешь инструкциям (Enter → Ctrl+V → Enter → ...)

# 4. Получаешь код от ИИ

# 5. Сохраняешь ответ
# → projects/amazon_scraper/AI_OUTPUT/03_scraper_answer.py
```
